Create Anki Flash Cards
=======================

This logic will process the files retrieved by `course-files` and generate placeholder Anki decks.

## Example
```
$ ./create-anki-decks.py ~/Fred\ Online\ Oral\ Prep/Course\ Files/
Using auto detected profile: Damian
[Who or what is a Master] Creating 6 under Freds M200 - Placeholder::Who or what is a Master
```

Note: The downloads are copyrighted material and only for personal usage relating to a subscribed course
